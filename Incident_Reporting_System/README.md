# Incident Reporting System
Hanz Nicolo C Mariano - BSIT 3A

## Files
index.html, style.css, script.js (reporters, categories, incidents, locations, investigations, findings, evidence, actions, resolution, closure), access.js (login, roles, access control, audit trail), reports.js (reports and dashboard)

## Run
Open index.html in a browser, or from this folder run: `python -m http.server 8000` and open http://localhost:8000

## Accounts (password for all: Pass1234, change before real use)
admin, reporter, officer, investigator, actionofficer, supervisor, management

## Notes
Data is stored in the browser (localStorage), so each browser has its own database.
